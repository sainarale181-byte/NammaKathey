# NammaKathey 📖✨

NammaKathey is an Android application built using Kotlin that helps users explore inspiring stories of heroes from different districts through interactive storytelling, quizzes, achievements, and text-to-speech narration.

## Features 🚀

- 📍 Explore heroes district-wise
- 📚 Interactive story pages
- 🔊 Text-to-Speech narration support
- 🧠 Quiz system for each hero/story
- 🏅 Achievement & badge system
- 🔍 Search functionality for districts
- 👤 Personalized onboarding experience
- 📱 Modern Material Design UI

## Tech Stack 🛠️

- **Language:** Kotlin
- **Platform:** Android
- **UI:** XML + Material Components
- **Architecture:** Activity-based Android architecture
- **Storage:** SharedPreferences
- **Other APIs:** Android TextToSpeech API

## Installation ⚙️

1. Clone the repository:

```bash
git clone https://github.com/your-username/NammaKathey.git
```

2. Open the project in Android Studio.

3. Sync Gradle dependencies.

4. Run the app on an emulator or physical Android device.
